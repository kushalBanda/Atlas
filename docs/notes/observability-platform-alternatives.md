# Open-Source Observability Platforms

SigNoz ([GitHub](https://github.com/SigNoz/signoz)) is an OpenTelemetry-native, self-hostable platform that unifies logs, metrics, and traces/APM in a single tool, built on ClickHouse. This note surveys OSS full-stack (or near full-stack) observability projects that compete with or complement SigNoz, verified against each project's own GitHub repo (README/About/LICENSE) as of **2026-08-24**. All star counts and license fields below were read directly from the GitHub API (`api.github.com/repos/<org>/<repo>`) on that date; license text was cross-checked against each repo's `LICENSE`/`LICENSE.md` file where GitHub reported "Other."

`grafana/phlare` was dropped — it was merged into `grafana/pyroscope` and no longer exists as a separate project.

## Per-Project Notes

**SigNoz** — Baseline for comparison. Described in its own repo as "an open-source, OpenTelemetry-native observability platform... Get logs, metrics, and traces in one tool with features like APM, distributed tracing, log management, infra monitoring." 31,930 stars, dual-licensed (MIT core, separate enterprise license for `ee/`). [Repo](https://github.com/SigNoz/signoz) · [License](https://github.com/SigNoz/signoz/blob/main/LICENSE)

**Prometheus** — "The Prometheus monitoring system and time series database," Apache-2.0, 65,800 stars. Metrics-only; commonly the metrics source that OTel-native platforms like SigNoz ingest from. [Repo](https://github.com/prometheus/prometheus)

**Grafana Loki/Tempo/Mimir** — Grafana Labs' three separate signal-specific backends (logs/traces/metrics respectively), each AGPL-3.0, unified only via the separate Grafana visualization layer — architecturally the opposite of SigNoz's single unified app. Star counts: Loki 28,779, Tempo 5,452, Mimir 5,216. [Loki](https://github.com/grafana/loki) · [Tempo](https://github.com/grafana/tempo) · [Mimir](https://github.com/grafana/mimir)

**Jaeger** — CNCF distributed tracing platform, Apache-2.0, 23,134 stars. Traces only, no native logs/metrics/APM UI. [Repo](https://github.com/jaegertracing/jaeger)

**OpenTelemetry Collector** — The vendor-neutral collector/pipeline (Apache-2.0, 7,448 stars) that SigNoz and most of this list ingest data through; not itself a storage/query backend or competing platform. [Repo](https://github.com/open-telemetry/opentelemetry-collector)

**Uptrace** — "Open source APM: OpenTelemetry traces, metrics, and logs," AGPL-3.0, 4,268 stars, ClickHouse-backed. Architecturally the closest single-app analog to SigNoz. [Repo](https://github.com/uptrace/uptrace)

**HyperDX** — "Open source observability platform unifying session replays, logs, metrics, traces and errors powered by ClickHouse and OpenTelemetry," MIT license, 9,860 stars. Direct SigNoz competitor with a more permissive (MIT, no separate enterprise carve-out at the top level) license. [Repo](https://github.com/hyperdxio/hyperdx)

**OpenObserve** — "Open source observability platform for logs, metrics, traces, frontend monitoring, pipelines and LLM observability... alternative to Datadog, Splunk, and Elasticsearch," AGPL-3.0, 21,443 stars, single-binary deployment. Closest in star count and positioning to SigNoz. [Repo](https://github.com/openobserve/openobserve)

**VictoriaMetrics / VictoriaLogs** — Separate Apache-2.0 projects for metrics (17,589 stars) and logs (2,187 stars) respectively; no native tracing/APM component, so together they cover two of SigNoz's three core signals. [VictoriaMetrics](https://github.com/VictoriaMetrics/VictoriaMetrics) · [VictoriaLogs](https://github.com/VictoriaMetrics/VictoriaLogs)

**Netdata** — GPL-3.0, 80,277 stars, "The fastest path to AI-powered full stack observability, even for lean teams." Real-time per-second infra-monitoring focus, expanding into full-stack but historically metrics/infra-centric rather than APM/trace-first like SigNoz. [Repo](https://github.com/netdata/netdata)

**Zabbix** — AGPL-3.0, 6,301 stars. Traditional infra/network monitoring and alerting tool predating OpenTelemetry; not OTel-native and lacks native distributed tracing/APM. [Repo](https://github.com/zabbix/zabbix)

**Elastic (Elasticsearch) / OpenSearch** — Elasticsearch (77,857 stars) is triple-licensed AGPL-3.0/SSPL-1.0/Elastic License 2.0 and is a search/storage engine; Elastic Observability (Kibana + APM Server on top) provides full-stack logs/metrics/traces but is a heavier, broader platform than SigNoz. OpenSearch (13,574 stars, Apache-2.0) is the AWS-led fork with more permissive licensing; its observability capability is delivered via plugins rather than being native. [Elasticsearch](https://github.com/elastic/elasticsearch) · [OpenSearch](https://github.com/opensearch-project/OpenSearch)

**Sentry (self-hosted)** — Functional Source License 1.1 (auto-converts to Apache-2.0 after 2 years per version), 44,610 stars. "Developer-first error tracking and performance monitoring" — error-tracking/APM-tracing-first, not a general logs/metrics platform, and the FSL restricts competing commercial use. [Repo](https://github.com/getsentry/sentry) · [License](https://github.com/getsentry/sentry/blob/master/LICENSE.md)

**Grafana Beyla** — Apache-2.0, 2,101 stars. "eBPF-based autoinstrumentation of web applications and network metrics" producing OTel data — an instrumentation tool, not a storage/query/UI backend; complementary to (can feed) SigNoz rather than competing with it. [Repo](https://github.com/grafana/beyla)

**Highlight.io** — Apache-2.0 core with a separate license for `highlight.io/`/`enterprise/` directories, 9,368 stars. "The open source, full-stack monitoring platform. Error monitoring, session replay, logging, distributed tracing, and more" — broader scope than SigNoz (adds session replay), frontend-monitoring-first heritage. [Repo](https://github.com/highlight/highlight)

**Coroot** — Apache-2.0, 7,887 stars. "Open-source observability and APM tool with AI-powered Root Cause Analysis. It combines metrics, logs, traces, continuous profiling, and SLO-based alerting" — eBPF/no-instrumentation approach vs. SigNoz's OTel-instrumentation-first approach. [Repo](https://github.com/coroot/coroot)

**Grafana Pyroscope** — AGPL-3.0, 11,637 stars, "Continuous Profiling Platform." Absorbed the formerly separate `grafana/phlare` project (which no longer exists as a standalone repo). Covers a specialized signal (continuous profiling) that SigNoz does not natively provide. [Repo](https://github.com/grafana/pyroscope)

**Parseable** — AGPL-3.0, 2,441 stars, "unified infrastructure observability platform built in Rust on a data lake architecture. It tracks logs, metrics, traces, and events." Direct full-stack competitor with a data-lake (vs. ClickHouse) storage architecture. [Repo](https://github.com/parseablehq/parseable)

**Quickwit** — "Cloud-native OSS search engine for observability," 11,539 stars, license mixed Apache-2.0/AGPL by component. Still actively maintained (latest release v0.9.0, July 2026; commits as recent as the observation date). Positions as an Elasticsearch alternative for log/trace search on object storage rather than a unified logs+metrics+traces+APM application like SigNoz. [Repo](https://github.com/quickwit-oss/quickwit)

## Notes on Methodology

- All star counts, license fields, `archived` status, and last-push timestamps were pulled directly from `https://api.github.com/repos/<org>/<repo>` on 2026-08-24.
- Where GitHub's license detector reported "Other" (SigNoz, Sentry, Elasticsearch, Highlight.io), the actual `LICENSE`/`LICENSE.md` file was fetched and read to determine the real license terms.
- `grafana/phlare` was excluded: it has been merged into `grafana/pyroscope` and is not an independently maintained project.
- All listed projects showed recent commit/release activity as of the observation date (none archived, none stale).
